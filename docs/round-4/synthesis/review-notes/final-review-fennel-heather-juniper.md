Exact formulas from `docs/round-4/ideas/Juniper/Juniper.tex:546–565`:

`N2 = b^p − 1 − a^p`, `N4 = −a^p b^p`, for `a,b : Z`, `p : N`.

- If `a ≡ 3 (mod 4)`, `2 ∣ b`, p is odd and `2 ≤ p`, then `4 ∣ N2`.
- Independently, if `2 ∣ b` and `4 ≤ p`, then `16 ∣ N4`, with no condition on a or p's oddness.
- Thus `(a,b,p)=(3,2,5)` simultaneously satisfies the combined helper, with `N2=−212`, `N4=−7776`, exact integer quotients −53 and −486.
- `(3,2,3)` still satisfies the first coefficient's premises, but `N4=−216` is not divisible by 16. This makes the benefit of operation-specific interfaces concrete.

The proof is elementary: write b=2k. For p≥2 its power is zero modulo four; the residue and oddness make `a^p≡−1 (mod4)`. For p≥4 the power `b^p` is divisible by sixteen, hence so is `−a^p b^p`. The first p≥2 bound is a library-theorem improvement, not an achievement of minimal-support search on a fixed graph. It is sufficient under oddness, not claimed globally weakest for all a,b,p. Fennel uses the sufficient combined p≥4 helper (`Fennel.tex:989–1030`); Heather does likewise (`Heather.tex:1249–1282`).

It tests dependent shared witnesses, unlike more arithmetic route examples.
